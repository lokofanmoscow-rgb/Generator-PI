# Генератор ПИ

Программа для Windows, которая берёт готовый протокол испытаний (`.docx`) как шаблон
и собирает новый для другого образца:

* **п. 3.1** — новое наименование образца;
* **п. 5** — «Количество компонентов составило N шт.»;
* **Таблица №4** — строится заново: для каждого компонента 5 элементов
  (Pb, Hg, Cd, общий хром, общий бром), для чистых металлов — 4 (без брома).
  Колонка «%» и интерпретация BL / X / OL считаются автоматически по пределам
  Таблицы №5 (ГОСТ IEC 62321-3-1-2016, Приложение А);
  Компонент никогда не разрывается между страницами: если он не помещается,
  то целиком переходит на следующую страницу («не отрывать от следующего» в Word);
* **Приложение №1** — новые фото по порядку номеров (по два на страницу), под каждым:
  пустая строка, «Фото №k», «Компонент. / Компоненты. <наименование>», пустая строка,
  «N компонент» / «N÷M компоненты».

Всё остальное в документе не меняется.

## Скачать

Готовая программа: [`exe/GeneratorPI.exe`](exe/GeneratorPI.exe). Установка не нужна,
достаточно запустить файл (Windows 10/11, 64 бит). Первый запуск занимает несколько секунд:
программа распаковывается во временную папку.

## Как пользоваться

1. **Шаблон ПИ**: выберите любой готовый протокол `.docx`. Программа запомнит выбор.
2. **Наименование образца**: например `Светильник светодиодный потолочный, марка "Homsly", модель 40W-W-R-4000K-GLSY`.
   В приложении кавычки автоматически станут «ёлочками», как в образце.
3. **Фотографии**: перетащите их в левую часть окна или нажмите «Добавить фото…».
   Программа сама распознаёт номера на фото (чёрные цифры с выносками), расставляет
   фото по порядку и считает количество компонентов. Щелчок по миниатюре покажет фото
   крупно с найденными номерами — так удобно проверить распознавание. Фото без номеров считается общим
   видом образца («Фото №1»). Если номер распознан неверно, поправьте поля
   «Компоненты с … по …» на карточке фото.
4. **Квадратики компонентов**: выберите сверху тип (чистый металл, провод, плата,
   СМД компонент) и щёлкайте по квадратикам. Можно проводить мышью с зажатой
   кнопкой. Правая кнопка снимает выделение. Всё, что не выделено, считается
   чистым полимером.
5. **Значения**: программа сама определяет, где нужен ввод, и подсвечивает эти
   ячейки жёлтым, а квадратики — красной рамкой:
   * провод — общий бром;
   * плата и СМД компонент — свинец и общий бром.

   Формат: `120 ± 12` (можно `120 12`, `120+-12`, `120/12`). Остальные ячейки по
   умолчанию «Менее 10», любую можно изменить.
6. Нажмите **«Сгенерировать ПИ»** и выберите, куда сохранить файл.

## Для разработчика

```
generator_pi/
  app.py           окно программы (wxPython)
  ocr.py           распознавание номеров на фото и раскладка диапазонов по фото
  docx_builder.py  сборка нового .docx из шаблона
  values.py        типы компонентов, разбор значений, BL/X/OL
  models/                  модели PaddleOCR (распознавание и детектор текста)
main.py            точка входа
GeneratorPI.spec   сборка exe (PyInstaller)
```

Распознавание номеров (на фото в полном разрешении, до 4096 px):
1. «Чернила» — тёмные и почти бесцветные пиксели: тёмная зелёная кайма вдоль линий
   сетки коврика к ним не относится, иначе сетка сливается с цифрами.
   На снимке ищутся области из таких пикселей, похожие на цифры. Если к цифре
   вплотную подходит выносная линия, тонкая линия срезается.
2. Параллельно работает нейросетевой детектор текста PP-OCRv3 det: он находит
   числа, к которым прилипла линия.
3. Каждый кандидат читается моделью PP-OCRv3 rec, допускаются только цифры.
4. Перед чтением вертикальные линии, проходящие строку цифр насквозь (выноски
   соседних подписей), стираются — иначе они читаются как «1». Подписи, слипшиеся
   в одну строку («108 110 112»), делятся по промежуткам. Одиночная «1» принимается,
   только если похожа на цифру, а не на брусок (прорезь, кромку).
5. Из находок на одном месте остаётся лучшая; обрывок числа («5» от «105»)
   уступает целому числу. Белые цифры на тёмном (маркировка на корпусах деталей,
   надписи на плате) не засчитываются: у подписи тёмные только штрихи, фон светлый.
6. По всем фото сразу подбираются непересекающиеся диапазоны номеров.

Щелчок по миниатюре фото открывает его крупно: найденные номера обведены зелёным.

Модели PaddleOCR (Apache-2.0): `models/digits_rec.onnx` (PP-OCRv3 rec), `models/text_det.onnx` (PP-OCRv3 det).

### Сборка exe (Windows, Python 3.12 x64)

```
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm GeneratorPI.spec
```

Результат: `dist/GeneratorPI.exe`. Библиотеки Visual C++ кладутся внутрь exe,
поэтому отдельный «Visual C++ Redistributable» на ПК не нужен.

Проверка собранного exe без окна:

```
GeneratorPI.exe --selftest отчёт.txt шаблон.docx фото1.jpg фото2.jpg ...
```

### Тесты

```
pip install pytest
pytest tests                                   # без шаблона
GPI_SAMPLE_DOCX=путь/к/ПИ.docx pytest tests    # плюс сборка документа из реального шаблона
```
